# Tome of Ancestors

A Bannerlord mod that removes fallen heroes from the main clan list and places them in a separate section.

[![Nexus Mods](https://img.shields.io/badge/NexusMods-Tome%20of%20Ancestors-orange)](https://www.nexusmods.com/mountandblade2bannerlord/mods/10595)

## What it does

- Removes deceased clan members from the main clan list.
- Adds a separate "Tome of Ancestors" section to the clan encyclopedia page.
- Keeps your clan roster clean without losing access to your fallen heroes' history.

## Installation

1. Install [Harmony](https://www.nexusmods.com/mountandblade2bannerlord/mods/2006), [ButterLib](https://www.nexusmods.com/mountandblade2bannerlord/mods/2018), [UIExtenderEx](https://www.nexusmods.com/mountandblade2bannerlord/mods/2102) and [MCM](https://www.nexusmods.com/mountandblade2bannerlord/mods/612).
2. Download the mod from [Nexus Mods](https://www.nexusmods.com/mountandblade2bannerlord/mods/10595).
3. Extract the `TomeOfAncestors` folder into your `Modules` directory.
4. Enable the mod in the launcher.

## Compatibility

- Game version: v1.2.12, v1.3.15, v1.4.5 – v1.4.8
- No known conflicts with other mods.
